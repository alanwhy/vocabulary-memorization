- [已确认] 后端 `flashcardGroupSize = 30`，`GET /api/flashcards/queue` 提供本人到期单词，评分由 `POST /api/flashcards/review` 保存；单词 ID 使用返回的 `id`。
- [已确认] 队列、索引和累计数量为模块级单例，切换页面后保留；每次评分成功才累计并推进一张。

- [设计] 下一组加载成功后清空本组结果，失败时保留结果。下一组为空时沿用“今日复习完成”；进入结果页不自动请求下一组。
- [已确认] 已有 `senses[].translation`、`senses[].phonetic` 与 `speakWord(word_key)` 可满足释义、音标和播放读音，不需要新接口。

## 设计要点

1. 本组结果复用已有完成页，不新增路由或弹窗。三类数量同时展示，不认识与模糊分别列出。
2. 结果列表展示全部非空释义，以分号连接；音标取首个非空值，播放复用现有发音能力。不带例句、次数、词根、标签、近反义词或释义编辑交互。
3. 结果与队列进度放在同一单例，切出再返回仍可回顾。只在评分成功后记入；加载失败与快速重复操作不增加数量、不丢失结果。

## 边界行为清单

- [x] 空数据：空队列沿用今日完成；不足 30 个按实际数量统计；某类为零显示空提示；缺释义显示“暂无释义”，缺音标仍可播放读音。
- [x] 异常状态：评分失败停留当前词且不记结果；下一组加载失败保留旧结果并展示错误；首次加载失败提供重试，避免渲染空卡片。
- [x] 历史数据与结构：只增加前端内存状态，无数据库迁移，也不读历史评分来凑本组结果。
