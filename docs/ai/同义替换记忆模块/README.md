# 考研英语同义替换训练完整方案

状态：模块代码已实现；数据库与页面业务待验收。日期：2026-11-12。目标用户：浩原及本应用其他学习者。

## 1. 模块定位

在现有“背单词、闪卡”之外新增“同义替换”入口。围绕本人词汇和导入的考研阅读材料，练习辨认词、短语和句子的改写，并识别错误选项对原意的改动。

学习单位是“某个义项与语境中的替换关系”，不是一串无条件互换的近义词。认识原词与掌握替换关系分别记录。

默认考研通用，支持英语一、英语二；默认基础难度，支持进阶。设置随每次内容准备和练习保存，不要求先决定考试类别才能使用。

## 2. 第一版范围

| 功能 | 第一版行为 |
|---|---|
| 内容准备 | 选择本人单词或输入自选词，由 DeepSeek 生成关系和题目 |
| 真题素材 | 粘贴文章、题干、选项及正确答案，保存来源信息，提取真实语境中的替换 |
| 学习表达 | 每次先看最多 3 条新关系卡；也可以选择直接练习 |
| 语境题 | 判断在指定句子中哪种表达能替换目标表达 |
| 原文—选项题 | 判断哪个改写保留原文意思 |
| 解析 | 展示正确选项、对应表达、义项与每个干扰项改变的含义 |
| 复习 | 关系级间隔复习；换句子、换题型练习同一关系 |
| 错题回顾 | 展示易错关系、错误维度和已做题的解析 |
| 质量反馈 | 标记多解、解析错误、语境不自然或来源存疑，暂停相关题目 |
| 学习记录 | 正确率、独立答对比例、提示使用、待复习关系和主要错误类型 |

自动联网搜集真题、PDF/OCR 导入、整套试卷计时模拟、写作改写评分、公共共享题库属于后续范围。第一版的真题入口采用文本和来源链接导入，能够完成素材到训练的闭环。

## 3. 数据从哪里来

### 路线一：个人词库生成

1. 选择本人已录入的单词，已归档词也可选；优先使用标记的重要释义。
2. 当前近义词只作候选。DeepSeek 根据一个明确义项，建立适用于具体句子的替换关系和使用限制。
3. 每条关系生成最多 2 道不同语境的题：语境选择与句子改写各一道。
4. 系统做结构检查，再用一次独立上下文的 DeepSeek 请求盲审答案与含义；通过后保存。

没有个人词汇时可输入 1–5 个自选词作种子。此操作只准备本模块内容，不自动改动原有个人词表。默认选择常见用法，界面允许看到并纠正具体义项。

### 路线二：真题素材提取

1. 粘贴阅读文章或足够上下文、题干、四个选项和正确答案。
2. 填写材料标题；年份、英语一/二、题号和来源链接可选。
3. DeepSeek 先分析正确选项与原文的对应证据，再提取最多 5 条直接可解释的替换关系。
4. 系统展示原文证据、正确选项表达和替换解释，由用户确认提取结果。
5. 基于确认的关系生成并校验变式练习。

第一版只提取有直接语义对应证据的关系。依赖全文主旨、作者立场推断或上下文不足的题保留为材料，并解释为什么暂时不能生成替换练习，不强行制造对应关系。

来源链接仅作记录，第一版不会仅凭一个链接自动取得文章。来源真实性与题目语义正确性分别管理：模型检查不能把用户提供的材料认证为官方真题。

### 内容标识

- “生成练习”：由本人词汇或自选词生成。
- “基于真题素材”：基于用户提供、已确认提取关系的材料生成的变式题。
- 材料页标注“真题素材 · 用户提供”，可查看记录的年份、题号与来源。
- 每条关系和题目保存模型、生成时间、内容版本及材料引用。不能将生成练习标成真题原题或未经统计的“真题高频”。

## 4. 如何保证题目可用

出题不是一次生成就直接上线，而是四步：

1. **约束生成**：限定义项、句意、题型、难度和干扰项类型，要求四个选项只有一个正确答案。
2. **结构检查**：答案存在、选项去重、例句与表达匹配、四项解析完整、引用证据能在原文中找到。
3. **独立盲审**：不告诉复核请求预设答案，让模型独立判断哪些选项保留原意；只有一个正确且与生成答案一致才通过。
4. **使用后反馈**：用户反馈的题立即从本人题库暂停；已计入的相关作答作废，按其余有效作答重算该关系进度。

模型盲审能减少错误，仍需要人工抽检和用户纠错。不会把“两个请求都说正确”当作题目必然正确。

无合格题、语义多解、服务超时和额度用完分别说明。部分内容成功时可以先开始练习，失败部分单独重试。

## 5. 学习流程

### 模块首页

主要按钮：**开始练习、准备新内容、导入真题素材**。

展示待复习关系、新关系和最近学习结果；提供“关系本、错题回顾、真题素材”入口。有未完成的一组时显示“继续练习”。已有题库的练习不等待模型响应。

### 一组练习

1. 默认最多 10 题，优先约 6 道到期复习、4 道新关系；不足时在可用内容中补齐，仍不足则按实际数量开始。
2. 同组每条关系只出一道，避免刚看到答案就重复测同一关系。
3. 默认先展示最多 3 条本组新关系的学习卡，用户可跳过学习直接做题。
4. 题目页面显示原文和四个选项，先隐藏中文释义、答案与对应关系。
5. 选择答案后标记“确定”或“不确定”再提交；提供“不知道”和“查看词义提示”。
6. 提交成功后显示正确选项、对应表达及逐项解释，用户点击“下一题”继续。
7. 本组结束后回顾错误、不确定和使用提示的关系，查看下次复习安排。

答后立即重复同一道题只能作为回顾，不再累计训练成绩。切页、刷新、退出后重新登录能够恢复当前组与已提交结果。

### 两类题的区别

| 题型 | 原文 | 正确替换 | 训练目标 |
|---|---|---|---|
| 语境选择 | The committee decided to postpone the meeting. | put off the meeting | 理解 postpone 对应的延后含义与搭配 |
| 原文—选项 | The report accounts for the decline in sales. | The report explains why sales fell. | 识别短语和句子改写，保持主体与解释关系 |

语境题允许题目明确说明的必要语法调整；选项显示完整替换表达，避免单纯靠词性排除。句子题的错误项优先只改一个维度：范围、可能性、主体、时间、否定或因果角色。

基础难度以单句为主；进阶使用 1–3 句短语境、组合替换和减少原文高亮。难度是内容复杂度标签，不直接等同于历年考试分数难度。

## 6. 如何记录掌握与复习

- 答错、不知道或使用提示：次日复习，关系回到学习中。
- 答对但不确定：按“模糊”排期，不累计独立掌握次数。
- 答对且确定、未使用提示：按“记住”计算更长间隔。
- 至少两次相隔 24 小时、使用不同题目独立答对，才标为“已掌握”。初学后的正确记录属于学习表现，不声称已形成长期记忆。
- 已掌握关系仍保留到期复习；后续答错取消已掌握状态。

复用现有间隔计算方法，进度存到新模块。新模块作答不会改变原词的归档、背诵次数、重要释义或闪卡排期。

首页将普通正确率与独立答对比例分开；争议题、已删除内容和提交失败的作答不计入统计。训练题表现不等同于考研阅读提分，试用时通过未见语境和延迟回测观察迁移。

## 7. 等待与使用成本

- 点“准备新内容”才创建模型任务，默认每次最多 5 个词或 5 条关系；后台生成，用户可继续背单词。
- 通过检查的关系和题目逐条保存，可用部分先练，不需要等待整批完成。
- 同一用户复用已准备的内容；刷新、恢复进度、提交答案不调用模型。
- 第一版默认每用户每天最多 3 个新准备任务、实际模型请求最多 60 次、同时最多 1 个待处理任务；重试也计入请求额度。部署可配置这些上限。
- 全局默认一个出题工作线程，与原有查词并发分开；任务记录进数据库，服务重启后恢复未完成部分。
- 记录返回的 token 用量；没有可用单价和用量时不编造费用，具体成本按实际试用记录评估。

5–8 分钟是完成一组短句练习的目标节奏，不是首次生成的等待承诺。

## 8. 真题搜索的后续路线

在文本导入和训练闭环完成后，再接搜索：

1. 按考试类别、年份和题号检索材料。
2. 展示候选网站、标题和链接，优先核对来源，而不是直接把搜索摘要当正文。
3. 获取文章、选项与答案，去重并保存出处。
4. 核对完整性后进入已有的提取、确认、生成和训练流程。

自动搜索需要单独的搜索/内容获取服务；当前 DeepSeek 查词能力不能替代它。第一版不新增搜索供应商，不预置未经核对的批量真题。

## 9. 实现顺序与交付

1. 建立个人关系、题目、出题任务与训练进度存储。
2. 接入 DeepSeek 生成、盲审、缓存、部分成功与恢复。
3. 完成练习、解析、错题与关系复习。
4. 完成真题素材导入、提取结果确认和变式生成。
5. 接入导航和学习统计，完成必要后端检查，交给浩原手动验收页面与实际题目质量。

技术落点、接口和存储见 [详细设计](02b-design.md)，逐项任务与验证见 [实现计划](02-plan.md)，调研证据见 [需求与调研](01-spec.md)。

## 10. 完成标准

- 用户能从本人词汇生成合格内容并完成一组训练。
- 用户能导入一份有正确答案的阅读材料、确认替换关系并练习生成的变式题。
- 解析能说明正确对应与各干扰项对原意的改动。
- 错误、不确定、提示使用和独立答对影响关系排期符合本方案。
- 刷新、重复点击、网络失败、模型失败与服务重启不会重复计分或丢失已成功内容。
- 两个账号看不到彼此的材料、题库或训练进度。
- 既有单词与闪卡行为保持兼容。

实现与验证记录见 [03-review.md](03-review.md)。实际 DeepSeek 小批量、Go 测试、前端构建和代码检查通过；真实数据库事务与页面体验待手动验收，未部署上线。
