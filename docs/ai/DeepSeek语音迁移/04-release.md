## 恢复与构建过程

首次远端构建在前端模块转换及 Go 编译期间失去响应，公网 SSH 和 HTTP 超时。云控制台诊断未报告异常；VNC 显示历史内存耗尽和内核任务阻塞日志。不能仅据历史日志确认此次具体根因。

浩原明确授权普通重启及必要时强制重启，并完成云平台安全验证。普通重启进入停止中；尝试强制停止时平台返回 InvalidOperation.Conflict，因前一任务尚未结束。随后普通重启完成，SSH 恢复；没有成功执行强制停止。首次构建连接在重启后断开，旧版应用与原数据卷恢复运行。

恢复后确认系统内存约 1673 MiB、可用约 740 MiB、已有 1 GiB Swap，以及约 10 GiB 可用磁盘。先单独构建 frontend-builder，再利用前端缓存构建后端（Go 编译 61.7 秒）并更新后端容器，最终检查通过。本次沿用已有 Swap。
