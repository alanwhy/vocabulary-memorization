# 用户自己异步同步母库单词

修订：2026-11-12；Codex（GPT-6，具体子型号未提供）；frontend@1.24.0；规范 @sw/dev-skills@1.3.3。原 1.24.0 管理员入口已发布，用户明确纠正为个人中心入口，本记录取代旧方案。

## 需求陈述与适用范围

每个登录用户在个人中心“修改密码、重置次数”区域点击“同步所有单词”，异步补齐母库有释义的词。新增次数为 1，已有个人次数、归档和学习记录保留。移除用户管理同步按钮及其代用户操作能力。保留工作区其他模块改动。

## 影响面

继续使用 CodeGraph；本次影响个人中心、密码操作卡、AdminUsers、新同步路由、仓储方法及后台关闭等待。原始输出保存于 00-impact.md，追加本轮影响记录。通用请求封装和其他功能的释义过滤逻辑不改。

## 核心语义与数据流

- 已确认：目标仅取登录会话 user.ID，客户端不传目标 ID；普通用户和管理员均仅同步本人。
- 已确认：word_dictionary → words；按 (user_id,word_key) 唯一键识别重复，归档词也算已有。
- 定义释义：senses 是数组，至少一个非 error 义项的 translation 去掉空白后非空；跳过 SQL NULL、JSON null、空数组、空翻译、缺 translation 和错误占位。
- POST 快速返回任务状态，后台执行原有事务同步，GET 查询本人状态。页面刷新或重新进入可恢复等待。
- 页面防重入；服务端同用户运行任务复用。同步期间与“重置次数”互斥，已有数据不因同步改变。

## 设计要点

使用当前服务进程的后台任务状态，每用户保留最近一条任务，最大执行时间 5 分钟。复用进程取消和关闭等待，无新增表。状态 running/completed/failed/idle；完成返回新增数量及总数，个人中心重新读取统计。详细契约见 02b-design.md。

## 边界行为

- 无合格词或全重复：成功新增 0，不覆盖个人记录，不增加母库次数。
- 错误：未登录/禁用会话拒绝；数据库失败记录 failed，事务回滚，可重试；网络失败保留等待并查询结果。
- 历史兼容：复用现有表索引；不回滚上版已经同步到用户的词，以免删除个人数据。
- 并发：同用户仅一条运行任务，任务绑定当前会话用户；不同账号状态隔离。唯一键冲突不覆盖。
- 重启：浏览器刷新恢复同一服务内任务；服务器重启不持久化任务状态，事务取消或已提交，页面提示重试，幂等补齐不重复计数。
- mock：仅测试替身；无浏览器本地任务事实或外部模型调用。
- 契约：旧管理员入口返回 404；新 POST/GET /api/me/sync-words 同仓实现。

## 验收标准

- [ ] 用户管理不再出现同步按钮；个人中心修改密码区域出现同步按钮，普通用户可用。
- [ ] 请求快速返回，后台完成前显示“同步中，请稍候”，完成显示新增数量，刷新可继续查看任务。
- [ ] 仅复制实际有释义的词，新词次数 1；重复词和其他账号保持不变。
- [ ] 同步中不能重复启动或重置次数；失败可重试，网络中断后重新查询状态。
- [ ] 接口不能为其他 ID 发起同步或读取其他用户任务。
